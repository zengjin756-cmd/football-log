# 绿茵日志 ⚽

一款手机端足球运动记录 App 高保真交互原型 —— 记录训练、比赛与赛后总结，支持类微信的多账号好友体系。

## 功能亮点

- **记录**：训练 / 比赛 / 赛后总结，一条条记下你的足球轨迹
- **多账号**：内置 5 个演示账号（小马 / 阿豪 / 大鹏 / Kevin / 阿俊），每个人只能编辑自己的内容
- **类微信好友**：按名字搜索加好友 → 发申请 → 对方同意后互为好友；加好友才可见对方资料，陌生人不设防但🔒隐藏
- **球友动态**：记录"最近一起踢球"的日期，备注仅自己可见
- **统计**：出场 / 进球 / 助攻汇总
- **数据本地存储**：localStorage，无需服务器，纯前端单文件

## 快速体验

直接双击打开 `index.html` 即可。默认登录"小马"，可在「我的」页点头像切换到其他账号，体验完整的多用户好友流程。

## 技术说明

- 纯前端单文件实现（HTML + CSS + JS），无任何依赖
- 数据按账号分区存储于 localStorage（键 `footballLog_<uid>`），全局关系与当前登录账号分别存 `footballLog_rels`、`footballLog_cur`
- 单文件设计，方便本地直接运行与部署到 GitHub Pages
